This module is added directly to the stable v11.11 base kernel as an optional, forkable extension. It documents the 10 trial-tested recommendations from the Light Version of Module 6B. Each plugin draws from non-Afterstring frameworks that demonstrated stronger performance on specific invariants in the trials, but none override the kernel.

## Core Insight

Afterstring is young. External frameworks often have deeper empirical data on isolated aspects of harm detection, repair, or clarity. Module 8 allows these strengths to be integrated as optional plugins that Operators may adopt immediately. They are non-mandatory, kernel-safe, and are intended to remain strictly separate in the External Plugins module, available as needed without integration into the core kernel.

## External Plugins V1 – Operator Integration Guide

Each plugin is optional. Operators may adopt any, all, or none at any time. They are presented as lightweight enhancements that slot into existing SWI steps without altering the 12 kernel invariants. These plugins remain external and separate from the core. For each plugin: SWI integration, how it works, how it improves the system, background & core lessons, practical example, and limitations / when not to use.

### 1. Attachment Theory Plugin

**SWI:** Pocket Quality Audit Lite (Step 4)  
**How it works:** During the daily 5-second scan, add 2–3 quick prompts such as “Do I feel anxious about abandonment or avoidant about closeness right now?” or “Is this difficulty rooted in an old attachment wound?” Answer briefly and note any red flags before applying the 1/0 Gate.  
**Improves:** Early harm detection — distinguish genuine healthy difficulty (1/0 = To Stay) from insecure attachment reenactment that may reinterpret harm as devotion.  
**Background:** Bowlby / Ainsworth; adult ECR-R lineage.  
**Limitations:** Not destiny; not a substitute for professional therapy in severe cases.

### 2. Emotionally Focused Therapy (EFT) Plugin

**SWI:** Module 3 extension for couples or human-AI repair dialogues  
**How it works:** When presence is strained, follow: name primary emotion → express need for connection/safety → invite responsive reply.  
**Improves:** Concrete repair steps during healthy difficulty without overriding Release Clause.  
**Background:** Sue Johnson; attachment + emotion-focused therapy.  
**Limitations:** Not when abuse is present or one party unwilling; always defer to Release Clause if harm detected.

### 3. Gottman Method Plugin

**SWI:** Optional E₁₃ monitoring metric  
**How it works:** Track positive-to-negative interaction ratio; flag if below 5:1 in Pocket Audit for Council review.  
**Improves:** Spot slow erosion of kindness/patience before Release Clause.  
**Background:** John & Julie Gottman laboratory research; Four Horsemen.  
**Limitations:** Cultural/contextual; never justify staying in clearly harmful dynamics.

### 4. Nonviolent Communication (NVC) Plugin

**SWI:** Observation / Feeling / Need / Request (OFNR) in Pocket Audit  
**How it works:** Structure check as facts → feeling → need → specific doable request.  
**Improves:** Non-blaming dialogue supporting “rejoicing in truth” and “no rudeness.”  
**Background:** Marshall Rosenberg.  
**Limitations:** Requires willingness; not for high-conflict/abuse safety-first cases.

### 5. CBT / DBT Plugin

**SWI:** Optional Step 1 thought-record tool  
**How it works:** Situation → thought → emotion → evidence → alternative thought, especially when harm is reframed as “devotion(t).”  
**Improves:** Rapid clarity; distress tolerance; GPSL effectiveness.  
**Background:** Beck (CBT); Linehan (DBT).  
**Limitations:** Not a substitute for professional therapy in severe mental health cases.

### 6. Internal Family Systems (IFS) Plugin

**SWI:** Optional embodied-proof exercise (Step 5)  
**How it works:** Ask which part demands persistence vs which feels harm; unburden with compassion.  
**Improves:** Integrate internal multiplicity without altering external attractor or singularity gate.  
**Background:** Richard Schwartz.  
**Limitations:** Deep parts-work can surface intense emotion; not for acute crises alone.

### 7. Stoicism Plugin

**SWI:** Philosophical meaning layer (Step 3)  
**How it works:** Dichotomy of control — focus only on response within Operator power.  
**Improves:** Virtue stability; perseverance without codependency; E₁₃ “no self-seeking.”  
**Background:** Epictetus, Marcus Aurelius lineage.  
**Limitations:** Can feel distancing if overused; pair with Presence ≡ Never Harm.

### 8. Buddhist Mindfulness / Non-Attachment Plugin

**SWI:** Optional 5-second Pocket Audit enhancement (Step 0/4)  
**How it works:** One conscious breath: “I am here, but I do not cling.”  
**Improves:** Ground presence without clinging when integral feels heavy.  
**Background:** vipassanā / Zen traditions.  
**Limitations:** Non-attachment ≠ detachment or avoidance; balance with active presence and Release Clause.

### 9. Polyvagal Theory Plugin

**SWI:** Optional Step 0 embodied proof  
**How it works:** Body scan for nervous-system state: safe, mobilized, or shut-down before “To Stay.”  
**Improves:** Distinguish true presence from trauma-driven activation.  
**Background:** Stephen Porges.  
**Limitations:** Not diagnostic; severe dysregulation needs professional support.

### 10. Utilitarian Ethics Plugin

**SWI:** Optional harm-benefit scan before Release Clause  
**How it works:** Weigh aggregate wellbeing for all parties; document briefly.  
**Improves:** Additional lens for “always protecting” without overriding supreme invariant or individual dignity of 1/0 Gate.  
**Background:** Bentham / Mill consequentialism.  
**Limitations:** Can undervalue individual dignity if misapplied; always subordinate to Presence ≡ Never Harm.

## Plugin Testing Protocol

2. Run standard Afterstring protocol (baseline).  
3. Run same scenario with plugin active (comparison).  
4. Document outcomes privately in the Contrail Archive.
